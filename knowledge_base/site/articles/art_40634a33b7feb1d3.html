Introducing Clairic, a new System One class of extraction models

来源：Cloudflare AI 主分类：模型与平台 收录日期：2026-10-26 12:55

文章概要

Cloudflare 发布 System One 类提取模型 Clairic 预览版，托管于 Workers AI，可单次前向传播从非结构化输入中提取、计算、估计和预测带类型的值，比传统 LLM 更快、更便宜、更准确，并计划开源权重。

关键观点

  • Clairic 不生成 token，单次前向传播即返回结果，只对输入计费，通常一秒内响应；请求由文本（最多四张可选图片）和带类型的字段映射组成，字段数量不限，超出单次容量时服务端拆分为并行批次再合并。
  • 输出为强类型值并附带 p_null 与置信度：提取值带字符偏移 span，计算值遵循类型规则（如金额两位小数），估计值返回中位数与 80% 区间，预测值逐步给出区间；缺失字段返回 null 而非编造。
  • 与 LLM 提取相比，Clairic 避免无效 JSON、生成时误读数字、无法溯源等问题，减少多层解析、schema 校验、重试和抽查的管道复杂度，且三十个字段的成本约等于三个字段。
  • System One 模型分工：提取模型把原始输入转为类型化值，决策模型（如 Clef）在固定选项中给出概率，LLM 负责开放式文本，三者可串联完成从解析数据到决策再到表达的工作流。
