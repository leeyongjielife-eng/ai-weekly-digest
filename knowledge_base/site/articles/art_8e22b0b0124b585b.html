Write your first prompt with the GitHub Copilot app

来源：github.blog 主分类：AI 产品与工具 收录日期：2026-08-17 01:39

文章概要

该文章面向GitHub Copilot应用初学者，讲解如何编写第一条提示词，包括选择合适的上下文和模型，并自信地开始首个任务。

关键观点

  • 在 GitHub Copilot app 中，Agent 会话需要先连接 GitHub 仓库或本地文件夹，才能让 Copilot 获取代码库上下文并执行任务。
  • 提示词无需特殊语法或完美措辞，用自然语言描述想做的改动即可，例如“给游戏列表添加按融资额排序选项”，然后通过迭代补充细节。
  • 模型选择器可按需切换：默认模型适合起步，复杂推理任务或首次结果不理想时可换用其他模型，不必在每次会话前预先配置。
  • 会话支持语音输入、切换不同 Agent 以及开启远程控制，远程会话允许在网页端继续同一任务，方便跨设备接续工作。
