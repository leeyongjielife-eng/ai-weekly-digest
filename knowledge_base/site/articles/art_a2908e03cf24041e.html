GitHub Copilot app for Beginners: How to build custom workflows with canvases

来源：github.blog 主分类：Agent 与自动化 收录日期：2026-09-28 04:46

文章概要

GitHub Copilot 应用中的“canvases”功能允许用户通过自然语言描述，创建可自定义、双向协作的界面，如看板、清单或仪表板，以适应特定的工作流程。这些画布使AI代理与用户能够实时共同工作和更新，从而减少适应工具的时间，提高工作效率。

关键观点

  • GitHub Copilot 应用的“canvases”功能使AI工具的界面可以围绕用户工作流动态生成，用户只需用自然语言描述所需界面（如看板、清单），无需编码或手动设计，改变了传统工具固定界面的限制。
  • Canvases实现用户与AI代理的实时双向协作，双方可同时更新共享界面，例如代理添加发布说明，用户移动卡片，这促进了“共同操控”的工作流，而非传统的指令-等待响应模式。
  • 创建定制工具门槛降低，用户通过简单的`/create-canvas`命令和自然语言提示，即可生成复杂的自定义界面，重点描述想看的信息、自己能直接更改的内容以及代理应能更新或执行的操作。
  • 创建的画布可作为扩展保存并重复使用，无论是个人私用还是团队共享，且用户可基于社区共享模板（如Awesome Copilot）进行定制，加快了特定AI工作流的构建和推广效率。
