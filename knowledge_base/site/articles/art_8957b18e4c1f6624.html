Everything we launched during Agents Week

来源：blog.cloudflare.com 主分类：AI 产品与工具 收录日期：2026-08-17 01:39

文章概要

Cloudflare在2026年8月的Agents Week期间发布了一系列新公告，涵盖Wallets、Radar等多个产品更新。

关键观点

  • Cloudflare 将 Agent 视为继 AI 应用之后的新一类软件，其挑战不止于模型本身，还涉及身份、通信、编排、记忆、可观测性和安全等基础设施层。
  • Cloudflare 提出 Agent Development Lifecycle（ADLC）概念，用于把 Agent 软件从原型推进到生产环境，并配套提供相应原语。
  • Cloudflare 将 Zero Trust 从用户和设备扩展到 Agent 自身，并分享了其在内部落地该方案的经验。
  • Cloudflare 提出 Agentic Internet 愿景，主张网站主、发布者和 Agent 共同构建一个同时服务人类与 Agent 的互联网，并强调执行层、开发生命周期、安全访问与社区支撑是 Agent Cloud 的关键组成。
