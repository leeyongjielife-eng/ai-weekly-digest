Muse Spark 1.3 matches GPT-5.6-Sol, confirming Meta Superintelligence as the newest Frontier Lab, >90% discount for training

来源：latent.space 主分类：模型与平台 收录日期：2026-09-07 03:57

文章概要

Meta 发布 Muse Spark 1.3，在 AAII 排名中位列全球第三，性能接近 OpenAI 和 Anthropic 的前沿模型，并承诺开放权重；其定价模式在用户同意用于训练时可享受超过 90% 的折扣。

关键观点

  • Muse Spark 1.3 在 AAII 排名中成为全球第三的模型，性能与 OpenAI、Anthropic 的前沿模型相当，并承诺开放权重，同时提供超过 90% 的训练数据换折扣定价。
  • 斯坦福正在将 AI 原生软件工程学科化，新课程替换了 85% 的 2025 年秋季材料，转向 agent 技能、上下文工程、MCP 门户、agent 就绪代码库设计等系统化 agent 工程主题。
  • Agent 评估正从任务完成转向 harness 质量：HarnessDev 要求模型从可运行的弱种子构建执行 harness，并按能力与执行 token 成本双重评分，但自进化 harness 的收益不稳定且依赖模型。
  • 技能检索存在聚合指标误导：Retrieval-Invoked Actual-Use Effect 方法发现，在检索实际触发的任务子集上，技能检索可能对同任务表现产生负面影响，尽管整体分数提升。
