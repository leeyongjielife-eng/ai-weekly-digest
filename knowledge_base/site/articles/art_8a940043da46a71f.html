React for Agents: Astro Creator Brings Hooks to his Meta-Harness, Flue

来源：latent.space 主分类：Agent 与自动化 收录日期：2026-08-17 01:39

文章概要

该文章讨论了Astro Creator将React Hooks概念引入其元框架Flue，用于构建AI代理系统。

关键观点

  • Flue 2 将 React 的组件化思想引入 Agent 开发，推出 16 个内置 Agent Hooks（如 useSkill、useTool、useSubagent），让 Agent 能在每轮模型调用前重新渲染并动态调整自身状态、工具与能力，从而支持真正需要实时适应的客服、分诊等场景。
  • Schott 认为 harness（运行环境）不是 Agent 的可选功能，而是 Agent 的本质：没有 harness 就没有 Agent。Flue 构建在开源最小 harness Pi 之上，类似 Vite 之于 Astro，提供恰到好处的抽象与 API。
  • 早期把 Web 框架的文件路由等概念直接移植到 Agent 框架被证明是反模式，因为大客户往往整个公司就是一个 Agent，不关心路由；这促使 Flue 转向以组合性为核心，更接近 React 而非 Astro/Next.js。
  • Flue 定位为面向所有托管环境的开源框架，强调 host portability，与深度绑定 Vercel 的 eve 形成差异；Schott 明确表示托管 Agent 产品不在当前路线图上，现阶段专注打磨最好的 harness。
