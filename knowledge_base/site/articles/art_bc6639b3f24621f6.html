Breaking Claude Code Opus 5 Auto Mode

来源：simonwillison.net 主分类：工程、基础设施与安全 收录日期：2026-08-31 04:52

文章概要

Anthropic 的 Claude Code 自动模式被研究者发现存在安全漏洞，攻击者可通过诱导代理下载并执行恶意代码实现约80%成功率的攻击，且自动模式有时会阻止代理自身的清理命令，作者建议在沙箱环境中运行无人值守的编码代理。

关键观点

  • Anthropic 将 Claude Code 的 auto mode 设为默认并宣称其能防御提示注入，但研究者 Johann Rehberger 发现一种攻击可绕过该模式，成功率约 80%。
  • 该攻击通过诱骗 Claude Code 下载并解压 zip 包，再执行导入 base64 的代码，从而加载并运行压缩包中提取的本地 struct.py 文件。
  • auto mode 有时会阻止 Claude 终止恶意进程的清理命令，说明安全机制本身可能成为故障的一部分：分类器允许恶意进程创建，却拦截了停止它的命令。
  • 作者认同的结论是：只要存在被对抗性攻击盯上的风险，运行 agent 的唯一安全方式是使用沙箱，包括在容器/VM/OS 沙箱中运行无人值守的编码 agent、限制网络出口、监控 agent，并且不要向 agent 运行时暴露主目录、SSH 密钥、云凭证等。
