ReviewBench: An open benchmark for AI code review

来源：github.blog 主分类：AI 产品与工具 收录日期：2026-10-12 05:22

文章概要

GitHub 发布 ReviewBench，一个基于 1.039 亿真实 PR 分布构建的 AI 代码审查开放基准，包含 219 个 PR、19 种语言，采用多源金标准与可配置指标，用于离线评估代码审查 Agent。

关键观点

  • ReviewBench 从 1.039 亿个 GitHub PR 中提取真实工作负载分布，最终选取 187 个开源仓库的 219 个 PR、覆盖 19 种语言，并刻意向多文件、可审查的中等规模 PR 加权，避免小改动主导评测。
  • 评测同时报告固定金标准指标与增强指标：固定金标准会随 Agent 能力提升而变得不完整，增强指标可识别 Agent 新发现的问题而非直接判错，跨系统比较以 grounded recall 为主。
  • 评估支持按严重程度、类别切片，并可通过调整 Fβ 中的 β 在召回与精确率之间切换偏好，排行榜随偏好重新排序，适配不同团队的审查策略。
  • Copilot 代码审查的离线评测与线上 A/B 实验方向一致：多模型集成审查实验预测精确率、召回率、评论量上升且单次审查成本下降，线上对应为 addressed rate +8.0%、召回 +13.6%、评论量 +61%、成本 -8.0%，严重问题评论预测 +227%、线上 +262%。
