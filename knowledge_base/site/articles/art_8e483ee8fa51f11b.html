[AINews] Hot Chips: OpenAI’s Jalapeño, Cerebras CS-5, Groq 3 LPX, Apple M6

来源：latent.space 主分类：工程、基础设施与安全 收录日期：2026-08-31 04:52

文章概要

该文章报道了Hot Chips大会上多家公司发布的新芯片产品，包括OpenAI的Jalapeño、Cerebras CS-5、Groq 3 LPX和Apple M6。内容聚焦于这些AI芯片的技术规格与发布动态。

关键观点

  • OpenAI 自研推理芯片 Jalapeño 首批基准显示：峰值吞吐下每瓦工作量比 NVIDIA GB200/GB300 高 1.5–1.9 倍，端到端延迟低 1.7–3.6 倍，高交互负载性能高 2.1–4.1 倍；标称 700W 但实测多在 550W 以下，年底部署，Gen 2/3 已在开发。
  • OpenAI 称 GPT-Astra + Codex 参与编写和优化底层 kernel，约两个月内让三个原计划外的开放权重模型在 Jalapeño 上达到高性能，部分 attention 与 MoE 模块比人类专家代码快 1.5–1.8 倍，说明 kernel/编译器工作正被纳入模型改进闭环。
  • Agent 性能越来越取决于 harness 而非模型选择：微软 AutoSaddler 把 harness 当代码离线修补 prompt、工具配置和控制逻辑，在 GAIA2、SWE-Bench Pro、Terminal-Bench 2.0 上分别提升 +9.0、+9.6、+10.0；另有研究提出 Harness Card 披露标准，因为换 harness 对分数的影响可能大于换模型。
  • 长周期软件工程仍远未解决：SWE Refactor Bench 覆盖 C→Rust、Maven→Gradle 等整仓库迁移，520 次运行仅 28 次通过全部三阶段，存活率 5.4%，20 个任务中 13 个无人解决；同时记忆系统正被重构为可编程状态（追加式事件日志 + 持久 Python kernel），而非压缩聊天历史。
