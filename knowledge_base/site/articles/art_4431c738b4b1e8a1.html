AI-powered fuzzing with the GitHub Security Lab Taskflow Agent

来源：github.blog 主分类：Agent 与自动化 收录日期：2026-09-28 04:46

文章概要

本文介绍了GitHub Security Lab推出的Fuzzing Taskflow，这是一个基于LLM Agent的自主模糊测试管道，旨在自动化C/C++项目的安全测试工作。它能处理从识别入口点、编写测试用例到执行模糊测试、分析覆盖率、分类崩溃并生成漏洞报告等一系列复杂任务，显著减少了人工干预的需求。

关键观点

  • AI Agent能够接管传统上需人工大量参与的迭代和复杂任务，如安全漏洞挖掘中的模糊测试用例编写、覆盖率提升和崩溃分析，从而实现高度自动化，释放人力资源。
  • 该模糊测试代理采用模块化架构，将LLM Agent的决策能力与独立工具的执行能力分离，即Agent负责策略制定，工具负责具体操作，这种设计提升了系统的灵活性、可维护性和功能组合能力。
  • 系统内嵌了一个自适应的覆盖率反馈循环，Agent能根据实时覆盖率报告动态调整测试策略，例如添加新的种子、修改测试用例或丰富字典，并通过“高原检测”机制智能地判断何时停止，优化资源使用效率。
  • 为处理复杂结构化输入，该AI驱动的模糊测试管道结合了多项创新机制，包括基于格式的预置字典与自定义变异器、从源代码动态提取字典、通过覆盖率反馈实时丰富字典，以及语料库拼接操作，显著增强了发现深层漏洞的能力。
