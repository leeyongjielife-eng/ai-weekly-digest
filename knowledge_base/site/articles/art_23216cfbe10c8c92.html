GitHub Copilot app for Beginners: How to teach Copilot about your codebase

来源：GitHub AI & ML 主分类：AI 产品与工具 收录日期：2026-10-19 12:49

文章概要

文章介绍四种让 GitHub Copilot 理解代码库上下文的方式：仓库级与路径级自定义指令、封装可重复流程的 Agent Skills、面向复杂任务的自定义 Agent，以及通过 MCP 服务器连接外部工具和数据源。核心思路是把团队约定和流程沉淀在仓库里，让 Copilot 自动加载，而不是每次任务都重复解释。

关键观点

  • 自定义指令分两层：.github/copilot-instructions.md 定义全仓库通用的架构、命名和测试规范，.github/instructions 下的文件用 applyTo 字段按文件类型精准生效，避免用一套规则套所有文件。
  • Agent Skills 适合封装只在特定流程中才需要的知识，例如 .github/skills/quality-checks 下的 SKILL.md 说明何时启用、跑哪些测试和 lint 脚本、各脚本检查什么以及常见失败如何排查，让 Copilot 按既定流程执行而非猜测命令。
  • 自定义 Agent 面向跨多个文件、需要多种工具和上下文的复杂任务（如无障碍审查），在 .github/agents 中定义其目标、指令、工具和项目上下文，相当于为某类反复出现的工作建立专门角色。
  • MCP 服务器把 Copilot 的能力扩展到仓库之外，例如接入 Playwright 后可让它在浏览器中打开并操作应用做手动功能验证，从而不仅依赖自动化检查，还能确认界面行为符合预期。
