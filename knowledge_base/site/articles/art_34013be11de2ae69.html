LaTeX renderer

来源：Simon Willison 主分类：AI 产品与工具 收录日期：2026-10-19 12:49

文章概要

Simon Willison 受 Tiny Little Office 将文档数据存入 URL fragment 的启发，用 Claude Code 构建了一个 LaTeX 渲染工具：通过 #fragment 传入 LaTeX 代码即可渲染，并支持压缩前缀、编辑器与渲染视图切换、从 URL/Gist 加载，以及 iframe sandbox 防 XSS。

关键观点

  • 把文档内容编码进 URL 的 #fragment，可让每个生成的文档变成可收藏、可分享的链接，且无需后端存储。
  • 为 Agent 提供 llms.txt 说明 URL 构造规则，Claude 能据此直接生成可渲染的文档链接，这是一种让 AI 工具可被代理调用的实用模式。
  • 用 iframe sandbox 隔离渲染内容以防范 XSS，并复用已有的 SVG in Markdown 工具中的 Gist/URL 加载机制，体现工具间能力复用的工程思路。
  • 技术栈选用 CDN 上的 Pako 做压缩、MathJax 与 faster-latex 做渲染、DOMPurify 做净化，并通过自定义压缩字典优化 LaTeX 的 URL 体积。
