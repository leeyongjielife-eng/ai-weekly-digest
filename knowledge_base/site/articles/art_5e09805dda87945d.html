How to continue a GitHub Copilot app session in VS Code

来源：GitHub AI & ML 主分类：AI 产品与工具 收录日期：2026-10-26 12:55

文章概要

介绍如何将 GitHub Copilot 应用中的 agent 会话直接迁移到 VS Code 继续工作，保留对话、代码改动和 worktree 上下文，实现从 agent 自动执行到人工审查、编辑、本地测试和推送 PR 的连续工作流。

关键观点

  • 会话不仅包含修改的文件，还记录任务、计划和对话历史；在 VS Code 中打开会话时，这些上下文与 diff、worktree 一并保留，无需重新描述任务或复制历史到新聊天。
  • 在 VS Code 中审查 agent 改动时，应检查代码是否解决问题、是否符合仓库约定、错误与边界情况是否处理、测试是否覆盖变更、是否修改了无关文件。
  • 人工编辑直接发生在会话关联的 worktree 上，手动修改与 agent 改动叠加，无需复制文件或重建分支；随后用集成终端运行测试、lint 和本地开发服务器验证行为。
  • 可在提示 Copilot 与手动编辑之间迭代切换，因为仍在原会话中，Copilot 能理解“更新后的标签”等指代；推送分支即更新会话已跟踪的 PR，无需手动重新关联。
