Claude Code for normal people: skills, voice mode, and how to collaborate with AI

来源：lennysnewsletter.com 主分类：工作方式与职业变化 收录日期：2026-08-17 01:39

文章概要

Grace Clarke 在 Claude 中重建了她的服务业务，将每周 20 小时的行政工作转化为一个自动化流程，涵盖提案、客户跟踪和电子邮件。

关键观点

  • Grace Clarke 用 Claude 搭建了 pipeline operator、proposal maker 和 Gmail 替代品，把整个服务业务跑在自建工具上，其中 Gmail 替代品不到 30 分钟就做出来了。
  • 她放弃传统提案，改用 Claude 生成的密码保护、可交互的 HTML 文档；并用 'voice guide' skill 文件让 Claude 的输出听起来像她本人，而不是 AI 套话。
  • 她教非技术客户用两步强制动作养成打开 Claude 的肌肉记忆，并主张用 'intent engineering'（意图工程）取代 prompt engineering。
  • 她的工作流是先在 Claude Code 里构建，再通过 Markdown session 文件把工作交接给 Cowork；同时用手机上的 Claude 在散步时处理健身追踪、植物管理等日常事务。
