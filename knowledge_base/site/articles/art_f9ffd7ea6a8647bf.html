GPT-6 Astra is a banger - here’s everything I’ve built

来源：lennysnewsletter.com 主分类：模型与平台 收录日期：2026-09-07 03:57

文章概要

作者获得 GPT-6 Astra 早期访问权限，用它完成了此前用 5.6 Sol 或 Fable 反复失败的任务，包括 ChatPRD 产品智能功能、3D 游戏、硬件改造和多个一次性编码项目。文章还讨论了 Astra 在浏览器/计算机使用、QA、UI 回归和桌面开发方面的实际表现。

关键观点

  • Astra 的计算机使用能力有明显不同，作者已将其用于生产工具，并用浏览器使用做 QA 而非构建，发现了自己可能遗漏的问题。
  • 作者曾用各种模型尝试六个月的一个功能，最终靠 Astra 达到 90% 完成度，说明模型能力跃迁能解锁长期卡点。
  • 作者认为 UI 真正回归，这对 SaaS 和 MCP 有影响；同时 Astra 能一次性生成 AIM 风格 Mac 应用和 Blender 3D 资产，3D 成为其新的能力基准。
  • 作者对速度、成本和是否值得作为日常主力工具给出了诚实评价，并总结了 Astra 擅长什么以及应该先尝试什么。
