Using the GitHub Copilot SDK for Java

来源：github.blog 主分类：AI 产品与工具 收录日期：2026-08-17 01:39

文章概要

GitHub Copilot SDK for Java 允许企业 Java 开发者通过惯用的 Java 代码（如注解和虚拟线程）来驱动 GitHub Copilot。

关键观点

  • GitHub Copilot SDK for Java 是首个真正框架无关的 Java AI 驱动方式，并借助 BYOK 支持实现 AI 供应商中立，摆脱了对 Langchain4j 或 Spring AI 等特定框架的依赖。
  • SDK 以 Maven 依赖形式提供（com.github:copilot-sdk-java:1.0.7-preview.1），支持在 Jakarta EE 和 Spring 等服务端环境中以 CompletableFuture、注解、lambda、虚拟线程等惯用 Java 方式创建 Copilot 会话、注册工具、发送提示并接收结构化响应。
  • @CopilotTool 与 @CopilotToolParam 注解让普通 Java 方法即可声明为模型可调用的工具，SDK 自动处理 JSON Schema 生成、参数解析与分发；该注解 API 目前为实验特性，需在 Maven 编译器中配置 -Acopilot.experimental.allowed=true 和 annotationProcessorPath。
  • 示例应用展示了基于 Jakarta EE 11 的房地产线索管理 Agent 流水线：每个查询在独立虚拟线程上启动隔离的 Copilot Agent，通过 Jakarta WebSocket 实时推送状态，并可用 session.on(...) 订阅工具调用与消息事件来构建响应式 UI。
