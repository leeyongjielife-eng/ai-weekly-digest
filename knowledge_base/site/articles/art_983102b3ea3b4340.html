Just a rumour of a bug is enough to find a security exploit these days

来源：simonwillison.net 主分类：工程、基础设施与安全 收录日期：2026-08-31 04:52

文章概要

OCaml项目安全补丁在公开讨论后数分钟内即遭自动化探测攻击，现代编码智能体已能仅凭漏洞传闻快速发现并利用安全缺陷。开源项目面临安全披露激增的困境，rclone维护者报告一个月内收到超40份安全披露，远超过去十年约20份的总量，现有开源漏洞披露流程亟需调整。

关键观点

  • OCaml 项目在补丁公开讨论后约十分钟内就出现针对百分号编码路径穿越的探测请求，说明自动化监控者正在实时扫描公开仓库，漏洞披露的窗口期已从数天压缩到分钟级。
  • 现代编码 Agent 已能仅凭漏洞的轻微线索就定位真实缺陷：Anil 用自己的 Agent 复现了这一点，并在 Claude Fable 拒绝任务时改用 DeepSeek V4 Pro 完成。
  • rclone 维护者 Nick Craig-Wood 证实同类压力：项目前十年仅收到约 20 个安全披露，最近一个月超过 40 个，约 75% 有值得排查的实质内容，即便用 AI 工具分诊仍耗费大量时间。
  • AI 驱动的漏洞发现速度与现有开源禁运/协调披露流程不兼容，且 GitHub 分配 CVE 的周期从 2-3 天拉长到 3-4 周，迫使维护者以 CVE-PENDING 状态发布补丁版本，社区需要新的安全流程。
