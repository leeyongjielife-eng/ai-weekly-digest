How canvases make agentic workflows visible, steerable, and cost-efficient

来源：github.blog 主分类：Agent 与自动化 收录日期：2026-08-24 01:41

文章概要

GitHub 博客文章探讨了如何利用画布（canvases）让智能体工作流更可见、可操控且成本高效，作者分享了在智能体工作流中使用画布的经验，并指出聊天适合表达意图但智能体工作易在滚动中丢失。

关键观点

  • 聊天界面适合表达意图，但代理执行真实工作后会变成冗长的滚动记录，计划、决策点、验证和审批时刻被埋没，导致需要从历史中重建上下文，产生协调税。
  • 画布为代理工作流提供持久、共享的表面，使状态显式且可检查，人类可以引导和审批，代理可以更新和推进，双方无需反复重放上下文即可保持对齐。
  • 作者从 Java Modernization Studio 和 Site Studio 两个画布中提炼出可复用的蓝图：明确定义工作流状态、呈现关键决策、立即持久化进度和草稿、保留明确的人类审批点。
  • 画布需要前期投入（Site Studio 约 2000 AI 积分，现代化画布约 3000 AI 积分），但对于重复性工作流，持久表面能减少重复提示、上下文丢失、来回沟通和返工，从而节省时间和成本并提升信任与吞吐量。
