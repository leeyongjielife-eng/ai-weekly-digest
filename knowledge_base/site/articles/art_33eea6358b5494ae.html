Some thoughts on the Navier–Stokes Millennium Prize Problem

来源：simonwillison.net 主分类：研究、政策与行业趋势 收录日期：2026-09-14 04:20

文章概要

OpenAI 使用未发布模型在约 88 小时内解决了 Navier-Stokes 千禧年难题，但被指利用了 Anthropic 员工 Levent Alpöge 与 NYU 教授 Tristan Buckmaster 近一年的相关工作信息。事件引发对 AI 训练数据边界、用户数据是否被间接利用以及数学领域「抢先发表」风险的讨论。

关键观点

  • OpenAI 的 agent 在 88 小时内解决 Navier-Stokes 问题，共发送 270 万条消息、消耗约 1300 亿输出 token；全部千禧年问题尝试合计 49 亿条消息、3000 亿输出 token，按 GPT-6 Astra 公开 API 价格估算约 1500 万美元。
  • Tristan Buckmaster 与 Levent Alpöge 已用 Claude 和 Codex 研究该问题近一年，8 月 15 日取得突破；OpenAI 在 9 月 1 日听到传闻后启动项目，9 月 5 日完成，时间线引发「抢先发表」争议。
  • OpenAI 承认无法排除去标识化的用户使用数据间接帮助了模型改进，但声称未直接访问用户数据，且双方证明结果在 Euler 情形（forced vs unforced）上存在显著差异。
  • 作者类比网络安全领域：仅凭「漏洞存在」的传闻就足以驱动 agent 找到 exploit；数学领域可能同样如此，只要知道有未发表解法，就可能触发数百万美元的 LLM 算力竞赛抢先完成。
