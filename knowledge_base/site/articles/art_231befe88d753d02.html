Claude Haiku 5.5

来源：simonwillison.net 主分类：模型与平台 收录日期：2026-10-12 05:22

文章概要

Anthropic 发布 Claude Haiku 5.5，定价与 GPT-6 Luna 对齐（10 万 token 内 $0.10/$0.50），但采用更耗 token 的新分词器，实际成本上升；同时 Anthropic 为订阅用户提供每月 API 额度并下调 Sonnet 5.5 缓存读取价格。

关键观点

  • Haiku 5.5 在 10 万 token 以内与 GPT-6 Luna 同价且基准分数更高，但超过 10 万 token 后价格涨 5 倍至 $0.50/$2.50，而 Luna 到 27.2 万 token 才涨到 $0.20/$0.75，长上下文场景 Luna 更划算。
  • 新分词器使同一长提示消耗约 1.25 倍 token，构成隐性涨价，评估模型成本时需按实际 token 用量而非标价比较。
  • Haiku 5.5 无法关闭推理，默认 medium 档；低档生成 SVG 约 7 秒、0.0936 美分，最高档耗时 5 分 9 秒、3.3826 美分，说明推理档位对延迟和成本影响显著。
  • Anthropic 为 Max 5x、Max 20x 和 Team 订阅者提供每月 $100/$200/最高 $500 的 API 额度，额度与订阅费等值、不滚存，且可关闭自动充值以避免超额账单。
