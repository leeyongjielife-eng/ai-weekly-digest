How 3 Java Champions are using GitHub Copilot for increased productivity

来源：GitHub AI & ML 主分类：AI 产品与工具 收录日期：2026-10-26 12:55

文章概要

三位资深 Java Champion 分享了在生产与开源项目中使用 GitHub Copilot 的具体做法：AI 能大幅压缩开发时间，但开发者仍需提供上下文、验证结果并对交付负责。

关键观点

  • Vlad Mihalcea 用 Copilot 将原本需数周的功能开发压缩到两天，并训练自定义 skill 模仿自己 65 篇文章的行文风格，让生成的文档与代码符合既有规范。
  • Patrick Baumgartner 强调“委托执行而非委托责任”：迁移 900 张教学幻灯片时先定义目标、约束与验证方式，再用截图、PDF 和并排运行做证据化验收，全程约 8-10 小时。
  • Copilot 可作为“陪练”挑战方案假设：在数学学习应用中，它促使作者放弃通用化设想，转而对齐瑞士各州课程顺序，并采用无后端架构避免收集儿童数据。
  • 按任务类型切换模型：深度思考用大上下文、高推理档模型，生成报告、发布说明等简单任务用轻量模型以节省 token。
