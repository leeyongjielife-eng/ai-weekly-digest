## 读取方式

1. 测试当前功能时先看“测试数据索引”和“运行索引”；
2. 排查错误时只读取对应 `ISSUE` 章节及其关联的 `RUN`；
3. 不需要默认读取全部历史记录。

- `AGENTS.md` 只保存永久规则和路由；
- `README.md` 是用户项目说明书；
